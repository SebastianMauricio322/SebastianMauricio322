## 📁 Proyectos destacados

### 📡 [Análisis de cobertura móvil en el Perú (OSIPTEL)](https://github.com/SebastianMauricio322/analisis-cobertura-movil-peru)
Proyecto de punta a punta con datos abiertos oficiales: 51 000+ registros de cobertura por operadora y una serie histórica 2010-2019.

- **SQL (PostgreSQL):** limpieza documentada (codificación, columnas mal tipadas, inconsistencias de texto) y 10 consultas con CTEs y funciones de ventana.
- **Power BI:** dashboard de 3 páginas, cada una para una audiencia distinta (Dirección, Ingeniería, Comercial), con medidas DAX avanzadas.
- **Auditoría y corrección:** tras una revisión externa, identifiqué un problema de granularidad (operador-centro vs. centro poblado), lo corregí en SQL y documenté la limitación restante.

**Herramientas:** `PostgreSQL` · `SQL` · `Power BI` · `DAX` · `Git`
